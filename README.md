# Miosmooth Tools & Services

ศูนย์รวมลิงก์เครื่องมือ 6 บริการ ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจหรือ build

## เปิดใช้งาน

ติดตั้ง Node.js แล้วรันจากโฟลเดอร์โปรเจกต์:

```bash
node server.js
```

เปิด http://127.0.0.1:8090

บนเครื่อง Linux ที่มี Bash, lsof และ curl สามารถใช้ `./start_server.sh` เพื่อรันเบื้องหลังได้ สคริปต์นี้จะหยุดโปรเซสเดิมบนพอร์ต 8090 ก่อนรันใหม่

## อัปเดตเว็บบนโฮสต์

รันจากโฟลเดอร์โปรเจกต์บนเครื่องที่ให้บริการเว็บ:

```bash
git pull --ff-only origin main
```

ไฟล์ HTML/CSS/JS ถูกอ่านใหม่ทุกคำขอ ไม่ต้อง build หรือรีสตาร์ต Node เมื่อแก้ไฟล์เหล่านี้ จากนั้นรีเฟรชเบราว์เซอร์ หากแก้ `server.js` จึงต้องรีสตาร์ตโปรเซส

การ merge บน GitHub ไม่ได้อัปเดตโฟลเดอร์บนโฮสต์เอง Repo นี้ไม่มีขั้นตอน deploy อัตโนมัติที่กำหนดไว้

## การใช้งาน

- เปิดเครื่องมือได้จากการ์ดทั้งใบ ลิงก์เปิดในแท็บใหม่
- ค้นหาด้วยชื่อ คำอธิบาย ประเภทงาน หรือโดเมน และใช้ร่วมกับหมวดได้
- กด `/` เพื่อไปช่องค้นหา และ `Esc` ในช่องค้นหาเพื่อล้างคำค้น
- กดดาวเพื่อบันทึกรายการโปรดในเบราว์เซอร์นี้ หากพื้นที่เก็บข้อมูลถูกบล็อก จะเก็บได้เฉพาะช่วงที่เปิดหน้า
- หาก JavaScript ไม่ทำงาน ลิงก์ทั้ง 6 ยังแสดงและเปิดได้ตามปกติ
- เว็บนี้ไม่ได้ตรวจสถานะออนไลน์หรือการทำงานภายในของบริการปลายทาง

## เพิ่มหรือแก้บริการ

แก้การ์ด `.service-card` ใน `index.html` รวมชื่อ คำอธิบาย URL และข้อมูล `data-search` / `data-category` พร้อมอัปเดตจำนวนในปุ่มหมวดและข้อความเริ่มต้น การ์ดอยู่ใน HTML เพื่อให้ใช้งานได้โดยไม่พึ่ง JavaScript
